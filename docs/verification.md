공개 대상에서 학번·개인 PC 경로·일반 인증 토큰 패턴이 검출되지 않았습니다.
과제 1 사진의 공개 PNG에는 EXIF 및 GPS 정보가 남지 않았음을 확인했습니다.
파일 하나의 최대 크기는 약 21.09 MiB이며, 영상·발표 파일은 Git 이력에 포함하지 않고 Release로 배포합니다.

코드·맵의 존재와 제공 영상 확인은 현재 공개본의 전체 기능 실행 검증을 대신하지 않습니다.
외부 에셋과 이미지 리소스 복원이 필요한 범위는 [소스 안내](source-scope.md)에 적었습니다.
