# 룰렛 회전 실습

[RouletteController.cs](Assets/Scripts/RouletteController.cs)에서 클릭 입력에 따른 상태값과 회전 속도의 변화를 다룹니다.
클릭하면 회전 속도를 설정하고, 상태에 따라 감쇠 계산을 적용합니다.

장면: [SampleScene.unity](Assets/Scenes/SampleScene.unity).
원래 상태 전환 로직을 유지했으며, 클릭별 시작·정지·감속 동작과 의도한 결과를 비교하는 것을 다음 과제로 남깁니다.
